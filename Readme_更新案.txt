【AnimalGatherer】（チーム名：Algorithm）

■ ゲーム概要
Unreal Engine 5.8で制作した、画面共有型のローカル2人対戦ゲームです。プレイヤーはマップに矢印を置いて動物を自分のゴールへ誘導し、制限時間内の得点を競います。

■ 主なゲームシステム
・矢印：各プレイヤーは最大3個まで配置できます。4個目を置くと、最も古い自分の矢印が消えます。
・動物：出現後は直進し、マスの中央で矢印を読み取って方向を変えます。自分のゴールへ誘導すると得点になります。
・空洞：空洞には矢印を置けません。動物が空洞に入ると落下します。
・反転スキル：相手が置いた矢印を反対方向に変えます。相手の矢印がない場合は使用回数を消費しません。
・加速スキル：すべての動物の移動速度が3秒間1.5倍になります。効果中に出現した動物にも適用されます。
・スキルは各プレイヤーがそれぞれ1試合につき各2回使用でき、使用後は各スキルに5秒のクールダウンがあります。
・チュートリアルで移動、矢印の配置、スキルの使い方を練習できます。
・制作者向けのマップ編集ワークベンチでタイルや空洞などを編集できます。

■ 操作方法
【キーボード：P1】
・W / A / S / D：カーソル移動
・方向キー：対応する方向の矢印を配置
・Tabを2秒長押し：チュートリアルをスキップ

【Xboxコントローラー：P1 / P2】
・方向パッドまたは左スティック：カーソル移動
・Y / A / X / B：それぞれ上 / 下 / 左 / 右の矢印を配置
・LB：相手の矢印を反転
・RB：動物を加速
・Startを2秒長押し：チュートリアルをスキップ

最初に入力を検出したコントローラーがP2、次のコントローラーがP1に割り当てられます。スキル操作にはコントローラーを使用します。

■ PRポイント
2人が同じ画面で動物の進路を取り合う対戦ゲームです。矢印の配置順と相手の矢印を反転するタイミングに加え、双方の動物に影響する加速スキルを使うタイミングが勝負を左右します。チュートリアルやマップ編集機能も実装しました。
