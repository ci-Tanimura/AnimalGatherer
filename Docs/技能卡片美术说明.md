# 技能卡片美术说明

日期：2026-10-06。用途：技能呈现讨论的第一版像素风卡片，不代表已接入游戏。

当前已确认使用第三版雪地卡片；下文保留各次迭代记录。技能规则、导入要求、HUD 布局和实施验收统一见 [技能系统实施资料](技能系统实施资料.md)，不按早期记录中的未定项重新设计。

## 目录约定

- `Art/SkillCards/` 保存技能卡片的原始 PNG 源图，供预览与后续导入 Unreal。
- 文件使用英文主题名与版本后缀；已有版本保留，新迭代另建文件。
- 首版文件：`skill-arrow-reverse-v1.png`、`skill-animal-speed-v1.png`。
- `skill-card-prompts-v1.json` 保存本次生成所用的完整工具输入，作为源数据供后续迭代参考。
- 源图先保持独立文件；本次不修改 Content 蓝图或导入设置。

## 视觉约定

两张卡片统一采用清晰的 16 位像素风、正面竖向构图、象牙色和金色卡框、深青色插画底色。卡框外透明，卡片内部不透明。主体分别为反向箭头和奔跑企鹅，缩小时仍应容易识别。

首版底部保留空白信息区。第二版按用户要求在留白中加入对应技能的日文名称，采用深色粗像素字体并居中；左右肩键提示、剩余次数和冷却仍由游戏 UI 叠加。卡片不固定反向技能的目标范围，也不固定加速倍率和时长。

## 生成方式与提示词摘要

使用内置 image_gen 工具分别生成两张独立图片。

- 共用提示：独立像素技能卡片，约 3:4 竖向比例，统一粗像素边框与阶梯状圆角；清晰像素块与有限配色；上部约 78% 为插画，下部约 22% 留白；卡框外真实透明；无文字、数字、水印或按键标记。
- 箭头反向：蓝色与珊瑚橙色的两条粗 U 形反向箭头，明确箭头端点与相反方向，小型网格底座和少量像素闪光。
- 动物加速：一只向右奔跑的可爱企鹅，深色身体、白色腹部、橙色喙与脚；金色速度线、少量像素扬尘和双箭头加速符号，小型网格底座。

## 验证状态

两张图片已生成并逐张目视检查：反向箭头与奔跑企鹅主题明确，均采用像素风、金色和象牙色卡框、无文字信息区。卡框样式细节存在差异，属于首版讨论稿。

两张图片均为 1086×1448 PNG，像素格式为 32 位 ARGB。抽样检查确认透明角落的 Alpha 为 0，卡片中央 Alpha 为 253，接近不透明；未对原图进行透明度或尺寸修改。已复制到项目的 `Art/SkillCards/`，原始生成文件保留。尚未在游戏 HUD 中验证缩放效果，也没有导入 Content。
